# FarmerConnect Design System — Premium Agricultural Green Theme

## Color Palette
| Token | Hex | Role |
|---|---|---|
| `ForestGreenPrimary` | `#14532D` | Top headers, active nav highlights, primary brand surfaces, user chat bubbles |
| `EmeraldGreenSecondary` | `#16A34A` | Primary action buttons, FABs, active tab indicators, focus borders |
| `GoldenYellowAccent` | `#FACC15` | Notification badges, ratings, language toggle chip, Crop Doctor CTA |
| `WarmCreamBackground` | `#F8FAF5` | Main scaffold and screen background across all 5 tabs |
| `PureWhiteCard` | `#FFFFFF` | Cards, bottom nav bar, tab strips, and all popup dialogs |
| `DarkCharcoalText` | `#1F2937` | Primary headings and body copy |
| `GreySecondaryText` | `#6B7280` | Supporting metadata, labels, inactive nav items |
| `FreshGreenSuccess` | `#22C55E` | Online status, positive trends, success states |
| `AmberWarning` | `#F59E0B` | Pending/warning badges |
| `SoftRedError` | `#EF4444` | Expenses, price drops, validation errors |

## Typography
- **Display / Headings / Titles:** `Plus Jakarta Sans` (`R.font.plus_jakarta_sans`)
- **Body / Labels:** `Inter` (`R.font.inter`)

## Shapes & Elevation
- **Cards:** `16.dp`–`20.dp` rounded corners, `PureWhiteCard` fill, `1.dp` `SoftSlateBorder` (`#E2E8DF`), subtle `1.dp`–`3.dp` elevation.
- **Dialogs:** `PureWhiteCard` container, `20.dp` corner radius, `ForestGreenPrimary` titles, `EmeraldGreenSecondary` confirm buttons.
